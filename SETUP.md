# SETUP — Gacha-dapp-JP

Setup personalizado gerado pelo **ZenBrief** a partir de `kauevictor30/Gacha-dapp-JP`.

## Como instalar no repo existente

1. Extraia este pacote **na raiz** do clone:
   ```bash
   cd /caminho/para/Gacha-dapp-JP
   unzip ~/Downloads/Gacha-dapp-JP-setup.zip
   ```
2. Revise `AGENTS.md`; revise `.opencode/`.
3. Abra no opencode e peça ao scout para validar o mapa:
   `revise o mapa do repo contra a árvore real e corrija o que estiver defasado`.

## O que veio no pacote

- `AGENTS.md` — regras e mapa do repo.
- `.opencode/agents/scout.md` — agente de exploração.
- `.opencode/commands/` — `/repo-brief` e `/repo-task`.
- `.opencode/skills/` — stellar, code-review, tailwind-ui, react-patterns, database, auth.
- `.opencode/opencode.json` — config base.
